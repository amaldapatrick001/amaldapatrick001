## About

I hold an MCA and work mainly with Java, Python, and Django. Most of my projects start as coursework or department competitions and end up as full applications — the plant nursery platform below, for instance, grew out of a final-year project into something with real ML components like disease detection and a recommendation engine.

I'm currently an Assistant Professor teaching Software Engineering and Web Development, and I keep building outside the classroom alongside that. Open to Software Engineer, Full-Stack Developer, or IT Consultant roles.
